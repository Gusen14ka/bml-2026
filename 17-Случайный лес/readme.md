# Случайный лес

Команда: 17

## Содержание каталога

Каталог `src/` содержит скрипты, демонстрирующие устройство и поведение алгоритма случайного леса (Random Forest).

| Скрипт | Описание |
|--------|----------|
| `_output.py` | Вспомогательный модуль: перехватывает stdout скрипта, дублирует вывод в консоль и сохраняет его в файл `NN_output.txt`. Используется всеми остальными скриптами |
| `01_single_tree.py` | Пошаговая механика одного дерева в ансамбле: бутстрап-выборка с возвращением и выделение OOB-объектов (out-of-bag) для валидации на микро-примере 8×2 |
| `02_max_features.py` | Сравнение BaggingClassifier (все признаки) и RandomForestClassifier (`max_features='sqrt'`): замер средней попарной корреляции предсказаний деревьев, показывающий, почему случайный лес снижает дисперсию ансамбля |
| `03_OOB_vs_HoldOut.py` | Сравнение OOB-оценки («бесплатная» внутренняя валидация по невошедшим в бутстрап объектам) и точности на отложенной hold-out выборке на датасете breast_cancer |
| `04_gini_importance.py` | Демонстрация biased Gini (MDI) importance: завышение вклада шумового признака с высокой кардинальностью и объективность permutation importance |
| `05_vs_decisionTree.py` | Сравнение одного глубокого дерева CART со случайным лесом: график насыщения accuracy при наращивании числа деревьев (1–200), результат в `05_output.png` |
| `06_vs_linearRegression.py` | Классическое ограничение леса — неспособность экстраполировать: на участке вне обучающего интервала прогноз RF «застревает» на уровне края данных, в отличие от линейной регрессии. Результат в `06_output.png` |
| `07_vs_GB_vs_KNN.py` | Бенчмарк RF против Gradient Boosting и k-NN на данных с 50 шумовыми признаками и без масштабирования: устойчивость RF к шуму и масштабу признаков, сравнение точности и времени обучения |

## Запуск кода

### Требования

- Python 3.10+
- Пакеты: `numpy`, `pandas`, `scikit-learn`, `matplotlib`, `tabulate` (для вывода `df.to_markdown` в `07`)

```bash
pip install numpy pandas scikit-learn matplotlib tabulate
```

### Запуск

Скрипты запускаются из каталога `src/` (важно: `_output.py` должен лежать рядом со скриптом):

```bash
cd "17-Случайный лес/src"
python 01_single_tree.py
python 02_max_features.py
python 03_OOB_vs_HoldOut.py
python 04_gini_importance.py
python 05_vs_decisionTree.py
python 06_vs_linearRegression.py
python 07_vs_GB_vs_KNN.py
```

### Результаты

Каждый скрипт выводит результат в консоль и параллельно сохраняет его в файл `NN_output.txt` (за это отвечает `_output.py`). Скрипты `05` и `06` дополнительно строят графики и сохраняют их как `05_output.png` и `06_output.png`. Все файлы `*_output.*` генерируются при запуске и не входят в репозиторий (добавлены в `.gitignore`).
